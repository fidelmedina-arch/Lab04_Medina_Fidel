# Python

## 1. Introduccion

### 1.1 ¿Qué es python

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general, conocido por su sintaxis clara y su gran parecido al lenguaje humano.

### 1.2 ¿Para qué utilizamos Python?

Utilizamos Python como un lenguaje de programación versátil para desarrollar aplicaciones web, automatizar tareas repetitivas, analizar grandes volúmenes de datos y crear modelos de inteligencia artificial.

## 2. Requisitos

*Para nosotros poder instalar python requerimos*:

- Acceo a conexion a internet
- Sistema operatibo compatible
