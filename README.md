### Gestión de tareas eficiente, colaborativa y moderna.

Taskflow es una aplicación web moderna y ligera, creada para que los desarrolladores puedan organizar sus actividades de manera eficiente a tiempo real y de manera colaborativa.

## Lista de Funciones
- **Tableros interactivos:** El uso de un tablero que permite organizar a tiempo real las tareas, donde se podrá observar su estado como "Por hacer", "En progreso" y "Completado".
- **Designación instantánea:** Permite delegar estas responsabilidades a un miembro en especifico a tiempo real, sirviendo para la rápida organización.
- **Notificaciones automáticas:** Informa al instante de la realización de un trabajo y permite también avisar cuando el plazo de uno esta previo a vencer.

## Tecnologías Utilizadas

El proyecto está construido utilizando el siguiente ecosistema tecnológico:

| Componente | Tecnología | Versión |
| :--- | :--- | :--- |
| **Frontend** | React.js | `v18.x` |
| **Backend** | Node.js / Express | `v20.x` |
| **Base de Datos** | PostgreSQL | `v16.x` |
| **Estilos** | Tailwind CSS | `v3.x` |

---
## Requisitos del Sistema

Previo a la instalación del proyecto, buscar si usted posee los elementos necesarios para su óptimo funcionamiento.

1. **Node.js:** Tener instalado el entorno de ejecución en su versión LTS.
2. **NPM o Yarn:** Contar con un gestor de paquetes para instalar las dependencias.
3. **PostgreSQL:** Tener una instancia de la base de datos activa y configurada.

---
## Instalación y Ejecución

Siga estos pasos sencillos para arrancar la aplicación en su entorno local:

1. **Clonar el proyecto:**
   ```bash
   git clone https://github.com
   cd Lab04_Medina_Fidel
   ```
2. **Instalar dependencias:**
   ```bash
   npm install
   ```
3. **Iniciar el servidor:**
   ```bash
   npm run dev
   ```
